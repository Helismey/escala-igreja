# Guia de textos (pt-BR)

| Elemento | Texto recomendado |
|---|---|
| Botão de confirmar | Confirmar presença |
| Botão de desmarcar | Desmarcar da escala |
| Botão de pedir troca | Pedir troca |
| Aprovar cadastro | Aprovar cadastro |
| Erro de conflito | Não foi possível escalar {nome}. Ela(e) já tem uma escala nesse horário. Escolha outra pessoa ou ajuste o horário. |
| Erro de limite | Não foi possível escalar {nome}. Já são 2 escalas neste dia. Escolha outra pessoa. |
| Slot aberto (alerta ao gestor) | Faltam pessoas para {função} em {data}. Ninguém disponível dentro das regras. Convide alguém ou ajuste o programa. |
| Estado vazio: programas | Nenhum programa ainda. Crie o primeiro para montar a escala. |
| Estado vazio: minha escala | Você não está escalado(a) nos próximos dias. Quando for, aparecerá aqui. |
| Confirmação de desmarcar | Desmarcar da escala de {data}? Vamos avisar quem assumirá seu lugar. Botões: Desmarcar / Manter escala |
| Cadastro enviado | Cadastro enviado. Assim que um responsável aprovar, você receberá um aviso. |

## Lembretes (TTS-free, texto de WhatsApp)
- D-7: "Paz do Senhor, {nome}! Daqui a uma semana você está escalado(a): {data}, {hora}, {função}. Confirme: {link}"
- D-2: "Lembrete: em 2 dias, {data} às {hora}, você serve em {função}. Confirme: {link}"
- D-1: "Amanhã é o dia! {data} às {hora}, {função}. Se não puder, avise por aqui: {link}"
- Substituto: "{nome}, você foi escalado(a) em {data} às {hora} ({função}) no lugar de um irmão que não pôde. Confirme: {link}"

Notas: mensagens curtas; evitar siglas; textos podem crescer 20 a 30% em telas pequenas.
