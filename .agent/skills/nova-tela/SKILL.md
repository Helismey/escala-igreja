# Nova tela

1. Ler `docs/design-system.md` e `docs/ux-copy.md`.
2. Definir perfis que acessam a tela e as permissões (skill seguranca-autorizacao-rbac).
3. Montar com componentes existentes e tokens; textos pela skill ux-copy-ptbr.
4. Validar mobile (skill acessibilidade-mobile) e estados: carregando, vazio, erro.
5. Garantir DTO mínimo por perfil (sem dados pessoais desnecessários).
6. Executar /revisar.
